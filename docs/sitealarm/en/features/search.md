# Search

The dashboard search lets you quickly find monitors, heartbeats, and app health checks without
having to scroll through the individual lists.

## Usage

Enter a search term — name, URL, token, or even a resource's ID all work. Use the arrow keys to
navigate through the results, `Enter` opens the selected entry, `Esc` closes the search.

Results are grouped by type:

- **Monitors**
- **Heartbeats**
- **App health checks**

The most relevant matches are shown per group. If you enter an ID directly, it's searched for
specifically instead of via full-text search.

## Visibility

The search only shows you resources that belong to your own account.
