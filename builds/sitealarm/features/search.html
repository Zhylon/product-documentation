# Suche

Über die Suche im Dashboard findest du schnell Monitore, Heartbeats und Application-Health-Checks, ohne lange in den einzelnen Listen scrollen zu müssen.

# Nutzung

Gib einen Suchbegriff ein — Name, URL, Token oder auch die ID einer Ressource funktionieren. Mit den Pfeiltasten kannst du durch die Ergebnisse navigieren, Enter öffnet den ausgewählten Eintrag, Esc schließt die Suche.

Die Ergebnisse sind nach Typ gruppiert:

  • Monitore
  • Heartbeats
  • Application-Health-Checks

Pro Gruppe werden dir die relevantesten Treffer angezeigt. Gibst du direkt eine ID ein, wird gezielt danach gesucht statt über die Volltextsuche.

# Sichtbarkeit

Die Suche zeigt dir ausschließlich Ressourcen, die zu deinem eigenen Konto gehören.
